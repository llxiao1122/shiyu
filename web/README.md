# 学习托管考试网站

网站从 APK 调用重建考试流程。入口为 `https://82.156.178.246/zgxy/`；考试详情提供“查询历史成绩”和“一键考试”。

## 自动答题

用户确认一次后，服务器读取可用历史答案，开启或继续已有会话，匹配并提交第一轮；无法确认的题目留空。平台核验通过后立即显示成绩并结束；未通过时，系统按平台复核策略读取该次错题和答案，再自动进行第二轮。第二轮出现未匹配题时按确认提示留空交卷，并如实显示平台成绩。考试由服务器继续处理，刷新页面不会中断；重新打开该考试可查看进度。

若刷新后登录态仍有效，页面会恢复原会话；同账号重新登录时也会保留同一服务进程内的考试会话。服务重启或会话被销毁后，内存中的运行任务、考试令牌和题目无法恢复；已有状态会保留，重新进入后可核对原会话，不会伪称已交卷。仅当网站确实失去原答题会话、平台查询显示尚未评分且用户确认时，才保留旧记录并尝试新考试；如果平台仍在评分、连接失败或交卷结果未知，则继续提示核对，不自动重新开考。如果平台返回相同的未决会话，系统停止自动交卷。

写请求超时或响应不确定时只读核验。平台明确返回业务繁忙时，仅在同一会话未评分且历史记录未出现的情况下有限重试；其他情况不重发。成绩须与同一会话历史记录核对后标为已确认。人脸策略或次数无法确认时停止。

## 运行与验证

需要 Node.js 24；在本目录运行 `NODE_USE_ENV_PROXY=1 node server.mjs`。服务默认绑定 `127.0.0.1:4174`，公网由 Caddy 提供 HTTPS。系统服务为 `learn-portal.service`。执行 `npm test`，浏览器测试需要 Chromium。

状态文件 `/root/learn/state/exams.json` 保存会话关联、操作状态和已核验成绩，不保存密码、令牌或题目答案。真实考试测试和限制见 `/root/learn/docs/real-exam-test-2026-10-30.md`。
